后端接口尚未实现。本期只保留菜单、路由与按钮的权限控制，避免权限矩阵出现“看得见但点不动”的空档。

后端接口
尚未实现，列表、创建、启停与删除均无接口
管理员在角色配置中勾选该权限，只会改变菜单与路由可见性，不会产生对应的接口能力。

模块上线前必须完成

  1. 声明权限码
    接口显式声明 apikey:view 等权限码；未登记权限的接口默认拒绝。
  2. 接入数据过滤
    若资源有归属，创建时写入 owner_id，列表与详情接入数据访问判定；平台级资源可明确标注不隔离。
  3. 纳入覆盖率测试
    鉴权覆盖率测试遍历全部 /api/v1 路由，未声明权限且不在白名单时测试失败。
