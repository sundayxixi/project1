RBAC 授权控制台

登录之后，你看到的世界由权限决定。

菜单、路由、按钮与数据行使用同一套判定：功能权限负责“能不能做”，数据范围与共享负责“能对哪些数据做”。

数据授权4 类资源 · 查看 / 管理双维度 · 资源级 ACL

深色：Agent 5 项浅色：业务模块其余已上线权限空白：预留或未持有

登录

使用用户名、密码与验证码登录。原型可直接选择一种身份体验。

验证码由后端签发，登录失败会返回 code=401 并清空本地 token。
或以内置角色快速体验

快速体验会以该角色写入原型身份并进入工作台。正式流程中，JWT 只携带身份信息， 权限集合与数据范围由 GET /api/v1/users/me 下发，不写入 token。
